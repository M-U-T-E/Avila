# Web Client

This directory contains the web client for the Avila chat application. It's built using React and TypeScript.

## Technologies

*   React
*   TypeScript
*   Webpack
*   HTML
*   CSS

## Setup

1.  Navigate to the `web-client` directory: `cd web-client`
2.  Install dependencies: `npm install`

## Development

1.  Start the development server: `npm run dev`

## Build

1.  Build the client: `npm run build`

## Run

1.  Start the client: `npm start`

## Structure

*   `src/`: Contains the client's source code.
*   `public/`: Contains static assets like `index.html`.
*   `package.json`: Lists the project's dependencies and scripts.
*   `tsconfig.json`: TypeScript configuration file.
* `webpack.config.js`: Webpack configuration file.
